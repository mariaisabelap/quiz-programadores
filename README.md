# Quiz Interativo para Programadores

Projeto web interativo desenvolvido para praticar os fundamentos do desenvolvimento front-end com HTML, CSS e JavaScript puro. 

O site apresenta um questionário focado em conceitos básicos de programação, com diferentes tipos de entradas de dados, validações e cálculo dinâmico de pontuação.

---

## Projeto Online

Teste a aplicação diretamente no seu navegador:  
👉 [Acessar Quiz Interativo no Netlify](https://quiz-de-programadores.netlify.app)

---

## Funcionalidades

- **Variedade de Inputs:** Perguntas de múltipla escolha (radio), seleção múltipla (checkbox), campo de texto, data, menu suspenso (select) e upload de arquivos.
- **Validação com RegEx:** Validação de regras para senha forte no campo de texto correspondente.
- **Cálculo de Pontuação:** Processamento dinâmico no envio, com exibição de mensagem e avaliação personalizada conforme o desempenho.
- **Acessibilidade e Semântica:** Estruturação em HTML5 semântico com labels associadas, marcas acessíveis e descrições detalhadas de imagem.
- **Página "Sobre Mim":** Seção dedicada à apresentação pessoal, lista de habilidades, outros projetos do portfólio e contatos.

---

## Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e tags de acessibilidade (`<section>`, `<figure>`, `<details>`, `<table>`).
- **CSS3:** Estilização responsiva, layout em Flexbox e padronização visual dos componentes.
- **JavaScript (ES6):** Manipulação de DOM, expressões regulares e validação do formulário.
